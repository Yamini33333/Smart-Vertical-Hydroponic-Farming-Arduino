# Smart Vertical Hydroponic Farming System

## Overview

An Arduino-based vertical hydroponic farming system designed to grow plants without soil. The system uses water mixed with essential nutrients and LED grow lights to support plant growth in a vertical setup.

## Features

- Soil-free plant cultivation using hydroponics
- Water-based nutrient delivery
- Vertical farming for efficient space utilization
- LED grow lights for plant growth
- Arduino-based monitoring and control
- Non-contact water-level monitoring
- Temperature and humidity monitoring
- Automated water circulation

## Working

1. Plants are grown without soil using a water-based hydroponic system.
2. Water mixed with essential nutrients is supplied to the plants.
3. Sensors monitor the growing environment and water level.
4. Arduino collects sensor data and controls the connected components.
5. LED grow lights provide the required light for plant growth.
6. A water pump circulates the nutrient-rich water through the vertical growing system.

## Technologies Used

- Arduino Uno
- Hydroponic System
- Nutrient Solution
- LED Grow Lights
- XKC-Y25 Non-Contact Liquid-Level Sensor
- DHT11 Temperature & Humidity Sensor
- Relay Module
- Water Pump
- Embedded C/C++ (Arduino)
